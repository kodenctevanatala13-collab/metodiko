## 📋 2. ДЕТАЛЬНАЯ КАРТА ФАЙЛОВ

| Путь к файлу | Назначение простыми словами | Кто использует | К какому сценарию относится |
| :--- | :--- | :--- | :--- |
| `index.html` | Единый главный портал Бюро стандартов с переключателем KZ/RU, демо-тренажером, калькулятором сметы и генерацией КП | Посетители сайта, заказчики, ЛПР | Главная витрина, тестирование симулятора, расчет бюджета |
| `assets/Metodico_logo_gold.png` | Векторный золотой логотип бренда в шапке сайта | Браузер | Визуальная идентификация бренда |
| `llms.txt` | Открытый стандарт описания компетенций для AI (Perplexity, ChatGPT, Gemini) | Поисковые нейросети | Привлечение клиентов через AI-поиск (LLM-SEO) |
| `robots.txt` | Инструкция для роботов Google и Яндекс | Поисковые боты | Индексация страниц в поисковой выдаче |
| `.gitignore` | Цифровой щит безопасности: блокирует отправку `.env` и секретов в интернет | Git / GitHub | Защита коммерческой тайны и ключей |
| `docs/architecture.md` | Техническая карта устройства проекта | Наталья, Antigravity AI | Управление кодовой базой и нормоконтроль |
| `Journal изменений/for-me.md` | Журнал на понятном русском языке: что изменилось и зачем | Наталья Коденцева | Контроль разработки владельцем |
| `Journal изменений/technical.md` | Технический журнал фиксации правок, тестов и хэшей | Antigravity AI, разработчики | История версий, аудит безопасности |
| `Опубликовать_на_GitHub.bat` | Автоматический скрипт отправки проекта на GitHub в 1 клик | Наталья Коденцева | Бесшовная публикация и автодеплой на Vercel |

## 🔒 3. ПРАВИЛА БЕЗОПАСНОСТИ ДАННЫХ
1. Файл `.env` с реальными API-ключами **ни при каких условиях** не добавляется в индекс Git.
2. В репозиторий выгружается только `.env.example` с пустыми шаблонами переменных.
3. Клиентские данные и телефоны из калькулятора обрабатываются исключительно локально в браузере клиента (клиент-сайд) и не сохраняются на сторонних серверах без ведома заказчика.
