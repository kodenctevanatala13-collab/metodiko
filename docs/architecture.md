## 🔒 3. ПРАВИЛА БЕЗОПАСНОСТИ ДАННЫХ
1. **Защита ключей:** Файл `.env` с реальными API-ключами и токенами изолирован и заблокирован правилом `.gitignore`. На GitHub попадает только пустой `.env.example`.
2. **Защита Google Таблицы:** Таблица находится в статусе «Доступ ограничен» (только аккаунт Натальи). URL таблицы не содержится в коде сайта и отправляется только Наталье в личные сообщения Telegram.
3. **Безопасность Webhook:** Google Apps Script принимает данные только методом POST (запись новой строки) и не содержит функций чтения или выдачи базы данных посетителям.
4. **Защита клиентских данных:** Посетитель сайта видит исключительно свои собственные данные, сохраненные локально в его браузере.
