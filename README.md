## 📌 О ПРОЕКТЕ
Веб-портал разработан для **ТОО «Метод и Ко»** («МЕТОДИКО») на основе принципов чистого вайбкодинга без абонентской платы и тяжелых зависимостей.

### Ключевой функционал:
1. **Интерактивный диалоговый тренажер:** боевая отработка возражений («Қымбат / Дорого») с подсчетом баллов и вердиктом методолога в реальном времени.
2. **Мгновенный билингвизм (KZ / RU):** строгий переключатель языка в шапке сайта, бесшовно переводящий весь контент, тренажер и модальные окна.
3. **Калькулятор сметы (5 категорий, 16 опций):** прозрачный выбор модулей с автоматическим формированием официального коммерческого предложения (КП).
4. **Витрина 4 эталонных решений:**
   * B2B-онбординг за 72 часа;
   * Эталонные УМКД/ПОӘК по ГОСО 2026 и тесты для Platonus/Moodle;
   * Аттестационные комплексы «Ұстаз» и авторские рабочие тетради;
   * Методологический аудит курсов и сборка из аудио (Voice-to-Course).
5. **AI-Ready (LLM-SEO):** микроразметка Schema.org, открытый паспорт компетенций `llms.txt` и оптимизация под поисковые нейросети (ChatGPT, Perplexity, Gemini).

## 🗂️ СТРУКТУРА ПРОЕКТА
* `index.html` — единая точка входа, интерактивный интерфейс портала.
* `assets/` — графические активы и оригинальные векторные логотипы.
* `docs/architecture.md` — подробная техническая карта папок и зависимостей.
* `Journal изменений/` — регламентные журналы изменений проекта:
  * `for-me.md` — человеческий журнал для владельца (формат CHG).
  * `technical.md` — технический журнал для разработчиков.
* `llms.txt` / `robots.txt` — поисковые спецификации и AI-индексация.
* `.gitignore` — цифровой щит безопасности (защита секретов и персональных данных).
* `Опубликовать_на_GitHub.bat` — скрипт синхронизации с GitHub в 1 клик.
